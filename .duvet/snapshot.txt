  SECTION: [2.3. Writes](#2-3-writes)
    TEXT[!MUST,implementation]: Every write MUST be one `TransactWriteItems` call.
    TEXT[!MUST,implementation]: The call MUST hold three actions: a counter update, an object action, and
    TEXT[!MUST,implementation]: an event put.
    TEXT[!MUST,implementation]: The counter update MUST set `n` to `n + 1` on condition that `n` still
    TEXT[!MUST,implementation]: has the value that the server read.
    TEXT[!MUST,implementation]: For a create, the object action MUST be a put on condition that the
    TEXT[!MUST,implementation]: object item does not exist.
    TEXT[!MUST,implementation,test]: For an update, the object action MUST be a put on condition that `rv`
    TEXT[!MUST,implementation,test]: equals the version that the server read.
    TEXT[!MUST,implementation,test]: For a delete, the object action MUST be a delete on condition that `rv`
    TEXT[!MUST,implementation,test]: equals the version that the server read.
    TEXT[!MUST,implementation]: The event put MUST be on condition that the event item does not exist.
    TEXT[!MUST,implementation]: Each call MUST set a `ClientRequestToken`.
    TEXT[!MUST,implementation]: If the transaction fails only on the counter condition, the server MUST
    TEXT[!MUST,implementation]: read the counter again and retry the same write.
    TEXT[!SHOULD,implementation]: The server SHOULD wait a short random time before each such retry.
    TEXT[!MUST,implementation]: If the transaction fails on the object condition of a create, the server
    TEXT[!MUST,implementation]: MUST return `409 AlreadyExists`.
    TEXT[!MUST,implementation]: If the transaction fails on the object condition of an update or a
    TEXT[!MUST,implementation]: delete, the server MUST read the object again and retry.
    TEXT[!MUST,implementation]: The server MUST reject a write whose event item would exceed the
    TEXT[!MUST,implementation]: DynamoDB item size limit.
    TEXT[!MUST,implementation]: The server MUST return `413 RequestEntityTooLarge` for such a write.

  SECTION: [2.4. Reads](#2-4-reads)

    TEXT[!MUST,implementation]: A list MUST read the counter before it queries the object items.
    TEXT[!MUST,implementation]: A list MUST read the counter again after the query.

    TEXT[!MUST,implementation]: If the two counter values are equal, the list MUST return that value as
    TEXT[!MUST,implementation]: its resource version.
    TEXT[!MUST,implementation,test]: A request for a list at an older, exact resource version MUST be served
    TEXT[!MUST,implementation,test]: by the watch cache, or it MUST fail with `410 Gone`.

    TEXT[!MUST]: Every store MUST keep them.
